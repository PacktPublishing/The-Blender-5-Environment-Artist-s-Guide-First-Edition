  Building a convincing 3D city requires more than modeling individual assets. You need to plan scale, establish a consistent visual language, organize complex scenes, and combine architecture, materials, props, and storytelling details into a believable whole.

  The Ultimate Environment Artist's Guide Part 1 begins a complete two-part Victorian environment project in Blender 5. Starting with reference gathering, planning, and blockout, you will shape the city through detailed architectural modeling and texturing. You'll create entrances, windows, balconies, roofs, signage, and storefront details before developing key locations including a bookstore and library. As the environment grows, you'll enrich the street with furniture, reusable community assets, and a period-inspired subway entrance, while learning how to keep a large scene coherent and manageable.

  By the end, you will have built and populated a substantial section of the Victorian city, gained a repeatable workflow for architectural environment art, and prepared the scene for the remaining buildings, assets, detailing, and final render completed in Part 2.

<details open>
  <summary><h2>Requirements for this book</h2></summary>

  This book uses **Blender 5.0** with the default keymap and left-click selection. You will need a computer running a version of Windows, macOS, or Linux supported by Blender 5.0. Check the [official Blender hardware requirements](https://www.blender.org/download/requirements/) to confirm compatibility. A compatible GPU can accelerate Cycles rendering, although CPU rendering is also supported. Before starting, download and extract the resource pack provided with the book. It includes materials, Geometry Nodes setups, reusable assets, and a human reference object. Chapter 1 explains how to organize these resources and register the folder as an Asset Browser library.

  The exercises build on one another, so save your work regularly and keep incremental backups and editable versions of procedural objects before applying modifiers or making major changes. Follow the Blender 5.0 instructions even where illustrations reference Blender 4; access to the original recordings is not required. Treat both parts of the book as one continuous project: Part 2 starts with the expanded city completed at the end of Chapter 10 in Part 1. Keep your scenes, editable generators, and reusable assets organized so you can continue the project smoothly.
</details>
